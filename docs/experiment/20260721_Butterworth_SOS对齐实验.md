# Butterworth SOS 与 SciPy 对齐实验

## 背景与问题

本实验验证 `pywayne.dsp.ButterworthFilter` 新增的二阶节级联（Second-Order
Sections, SOS）实现，并复现《对齐 scipy butterworth 滤波器》中的五条主要结论：

1. 高阶滤波器使用 SOS 比传递函数 `ba` 更稳定。
2. `filtfilt` 没有相位时延，但在某些有限长度信号上边界漂移可能比 `lfilter` 明显。
3. 分段流式滤波持续传递 `zf -> zi` 时，结果与整段单次滤波一致。
4. 第一段建议使用 `sosfilt_zi(sos) * x[0]` 做稳态初始化。
5. 后续每段必须使用前一段返回的 `zf`，不应重置为零。

Python 实现参考了 C++ `butterworth_filter.cpp` 的逐节 DF2T 计算顺序、
SOS 归一化、稳态 `zi` 传递增益和 `sosfiltfilt` 默认 `padlen` 计算规则。

## 实验环境与方法

- 代码：当前工作树的 `pywayne/dsp.py`
- 参考：`scipy.signal.sosfilt`、`sosfiltfilt` 和 `sosfilt_zi`
- 随机数：NumPy `default_rng`，种子在脚本内固定
- 数据类型：`float64`

实验使用下文固定的滤波器参数、数据长度和随机种子，通过
`ButterworthFilter` 与对应 SciPy API 逐项比较最大绝对误差、输出范围、
互相关时延及分段连续性。

## 实验配置

### SciPy 对齐

- 5 阶带通，采样率 200 Hz，通带 2–30 Hz
- 2,000 个高斯随机样本
- 比较 SOS 稳态 `zi`、单向滤波、最终状态和前后向滤波

### BA 与 SOS 稳定性

- 8 阶带通，采样率 200 Hz，通带 0.1–10 Hz
- 1,000 个高斯随机样本，随机种子 7
- SciPy SOS 结果作为稳定参考

### `filtfilt` 与 `lfilter`

复用 PDF/C++ 示例配置：10 秒 5 Hz 正弦波，采样率 100 Hz，2 阶原型
0.1–10 Hz 带通（最终数字滤波器为 4 阶）。时延用去除两端后的互相关峰值估计；
边界漂移指标是首尾各 1 秒输出均值的绝对差。

### 流式状态

- 2,000 点低频 + 高频正弦波，前 100 点增加 0.5 阶跃
- 4 阶低通，`Wn=0.2`，`fs=1.0`
- 拆分为 20 段，分别比较传递状态与每段重置状态

## 结果

| 验证项 | 指标 | 结果 |
|---|---|---:|
| SciPy 对齐 | `sosfilt` 最大绝对误差 | `1.40e-14` |
| SciPy 对齐 | `zf` 最大绝对误差 | `3.11e-15` |
| SciPy 对齐 | `sosfiltfilt` 最大绝对误差 | `2.33e-14` |
| 高阶窄带 | BA 最大输出/相对 SOS 误差 | `1.56e36` / `1.56e36` |
| 高阶窄带 | SOS 最大输出/相对 SciPy SOS 误差 | `0.832` / `2.71e-13` |
| 时延 | `filtfilt` / `lfilter` 互相关时延 | `0` / `2` samples |
| 边界漂移 | `filtfilt` / `lfilter` 首尾均值差 | `1.174` / `0.0104` |
| 分段滤波 | 传递状态相对整段最大误差 | `0.0` |
| 分段滤波 | 每段重置相对整段最大误差 | `1.311` |
| 首段初始化 | `zi=None` 的首样本误差 | `0.4767` |
| 首段初始化 | `sosfilt_zi * x[0]` 的首样本误差 | `1.11e-16` |

## 结论

PDF 的五条结论均得到复现：

1. 在 8 阶、0.1–10 Hz 的窄带设计上，单个高阶 `ba` 多项式已出现严重数值失稳；
   SOS 保持有界，且与 SciPy 的结果处于浮点误差量级。
2. `filtfilt` 在该有限长度、低截止频率很低的带通信号上时延为零，但边界均值漂移
   显著大于单向滤波。因此零相位不等于在所有指标上都更好。
3. 从零状态开始时，整段一次执行和首段 `zi=None`、后续持续传递 `zf` 的
   20 段流式执行逐点完全一致。
4. 信号首值为 0.5 时，默认零状态的首个输出为 0.0233；稳态 `zi * x[0]`
   初始化的首个输出为 0.5000，避免了人为的起始瞬态。
5. 若每段都把 `zi` 重置为零，与整段结果的最大误差达 1.311，证明后续段必须
   使用上一段的 `zf`。

## 限制与解释边界

- `filtfilt` 的漂移结论与滤波器带宽、信号长度、边界形状和 padding 方式有关；
  本实验证明“不总是更优”，不表示 `filtfilt` 普遍比 `lfilter` 差。
- 流式一致性要求整段和分段使用相同的首段初始状态。不能把整段的零状态
  结果与分段的稳态初始化结果直接比较。
- SOS 提高数值稳定性，但不改变 IIR 的因果性、相位延迟或前后向滤波的非实时性。

## 后续建议

- 高阶、窄带或截止频率接近 0/Nyquist 时优先使用 `output="sos"`。
- 在线使用 `lfilter`，首帧使用 `filt.zi() * x[0]`，后续帧传递返回的 `zf`。
- 离线使用 `filtfilt` 时检查两端边界，必要时调整 `padtype`/`padlen` 或截去边界。
